Abstract

Vision and touch provide complementary cues for object pose and local contact geometry. GelSlim 5.0 acquires both observations using one fixed camera, while VisTacFusion combines them through separate prediction paths for geometry and pose.

The complete abstract is available in the paper.

VisTacFusion

VisTacFusion estimates planar object pose, contact depth, and surface normals from visual and tactile observations. The model uses separate prediction paths for pose and geometry, with visual context shared through an attention bottleneck.

Feature extraction. Frozen SITR-B/16 and MAE-L/16 encode tactile and visual images. Projected tactile features initialize spatial and pose queries; projected visual tokens form memory M.

Pose estimation. Sixteen bottleneck tokens read visual memory. Across four fusion layers, tactile-initialized queries attend to the bottleneck and then to one another. The pose head concatenates the final pose token with mean-pooled spatial queries to predict rotation and translation.

Contact geometry. Tactile features from encoder blocks 3, 6, 9, and 12 bypass the pose-query trunk. Each receives a gated residual update from B4 before a DPT decoder predicts depth and surface normals.

Fusion data flow

Each fusion layer updates the bottleneck first, then the queries. Visual memory M remains fixed across all four layers.

Evaluation setup

Data. Every tenth sample within each real acquisition session is held out. Evaluation uses 12 known objects, with objects and sessions shared between training and validation. Object identity is provided to the pose queries.

Checkpoint selection. Depth and normals use the depth-selected checkpoint; rotation and translation use the angle-selected checkpoint. Each selected checkpoint is evaluated across all three input modes without reselection.

Metrics. Depth and normal MSE average over the full image. Rotation L₁ measures cosine and sine errors; angular error is reported in degrees. Translation L₁ averages coordinate errors normalized by half the object's target size.

Qualitative Results

Depth and surface-normal predictions from real observations, evaluated with a common depth-selected checkpoint across the three input modes.

Visual-only predictions miss much of the V-shape and corner contact regions. Tactile input recovers their boundaries, while paired input also reduces the irregular rod depth profile observed with tactile-only input.

Real–Simulation Co-training

We combine real observations with simulated visual and tactile images of the same object geometries. The main experiments use a real:sim ratio of 1:1.27. Modality dropout trains paired, tactile-only, and visual-only inference within the same architecture.
